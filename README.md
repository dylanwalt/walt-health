# WALT HEALTH

Live portal: https://dylanwalt.github.io/walt-health/

A private, phone-friendly workout portal. After unlocking, choose **Push**, **Pull**, **Shoulders**, or **Bonus** to open that workout directly. The first three sessions are fixed templates; Bonus is a short biceps pump for an optional fourth gym day. Exercise alternatives are available inside each session.

The password gate and WHOOP OAuth callback share the root URL. Keep that callback URL unchanged.

Workout templates and the current dashboard snapshot live in `data/plan.json` and `data/dashboard.json`. Garmin snapshots are regenerated by the health sync workflow; republish the portal to GitHub Pages after changes.

Brand colors are in `brand.json`; image assets are in `assets/`.
