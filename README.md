# WALT HEALTH

Live workout portal: https://dylanwalt.github.io/walt-health/

Choose Push, Pull, Shoulders, or Bonus to open a fixed workout immediately. Bonus is a biceps session. Workouts do not depend on a calendar date.

Workout templates live in `data/plan.json`; `data/dashboard.json` contains only the minimal app profile. No wearable sync or scheduled publisher is used.
